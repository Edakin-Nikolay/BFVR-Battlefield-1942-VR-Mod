# Документация нашей разработки (на русском)

Это папка документации **нашей ветки разработки** BFVR. Англоязычная документация
репозитория (`docs/`, `README.md`, `CHANGELOG.md`) остаётся на английском, как
требует оригинальный автор проекта. Здесь ведём только наши рабочие заметки.

## Правила документации

1. Все новые заметки о нашей разработке — здесь, на русском.
2. Формат: Markdown, один файл на тему. Имена файлов — ASCII (латиница), чтобы
   не было проблем с кодировкой консоли MSVC и git.
3. Каждый документ начинается с статуса: «актуально», «частично проверено»,
   «требует подтверждения на гарнитуре».
4. Разделение ответственности:
   - **математика** (матрицы, clamp, лучи) — проверяемо детерминированно тестами,
     утверждается здесь как подтверждённое;
   - **поведение гарнитуры** (что пользователь реально видит на Meta Quest 3) —
     утверждается только после подтверждения пользователем, с датой.
5. Проверенные инварианты дублировать (кратко) в англоязычный
   `docs/AI_DEVELOPER_HANDOFF.md`, чтобы он оставался истиной для обеих веток.

## Структура

- `README.md` — этот файл, правила и индекс;
- `math-conventions.md` — соглашения математики (row-vector D3D8, трансляция в
  строке 3, допуски, конвенция `Yaw`);
- `testing.md` — как тестировать наработки в игре (сборка, staging, установка);
- `status-ru.md` — текущее состояние наших правок на русском (кратко, без
  дублирования `PROJECT_MIND.md`).
